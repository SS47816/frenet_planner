# frenet_planner → [fiss_planner](https://github.com/SS47816/fiss_planner)

**This project now lives at [SS47816/fiss_planner](https://github.com/SS47816/fiss_planner)** as **FISS Planner**: FISS (RA-L 2022) and FISS+ (IROS 2023), with the FOP and FOP+ baselines, in one C++17 core with Python bindings, ROS 2 / ROS 1 nodes and Lanelet2 / CommonRoad / CARLA support.

- Code, issues and discussions: https://github.com/SS47816/fiss_planner
- Documentation: https://ss47816.github.io/fiss_planner/
- Interactive replay: https://ss47816.github.io/fiss_planner/demo/

```bash
pip install fiss-planner
```

The `frenet-planner` package on PyPI now installs `fiss-planner`. `import frenet_planner` keeps working, with a deprecation warning; new code should use `import fiss_planner`.

The history of this repository (formerly `frenet_optimal_planner`) is kept here; the project's code continues in fiss_planner.
